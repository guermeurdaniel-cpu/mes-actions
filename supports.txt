# =============================================================================
#  CATALOGUE DES SUPPORTS
# =============================================================================
#
#  Ce fichier decrit CE QUI EXISTE dans le portefeuille : pour chaque valeur, son
#  identifiant, son enveloppe, l endroit ou aller chercher son cours, et la facon
#  de la classer dans la synthese.
#
#  Il ne dit rien de ce que tu possedes : les quantites et les prix d achat sont
#  dans apports.csv, qui est un journal date. Deux fichiers, deux roles :
#      supports.txt  ->  la fiche d identite des valeurs      (change rarement)
#      apports.csv   ->  l historique de tes mouvements       (change souvent)
#
#  Ce fichier est lu par le tableau de bord (index.html), par le recuperateur de
#  valeurs liquidatives (scraper.py) et par l historisation du patrimoine
#  (patrimoine.py). Ajouter une valeur au portefeuille se fait donc ICI, et
#  nulle part ailleurs.
#
# -----------------------------------------------------------------------------
#  COMMENT C EST ECRIT
# -----------------------------------------------------------------------------
#
#  Un support = un bloc. Le titre entre crochets est l intitule, c est lui qu il
#  faut recopier dans apports.csv et c est lui qui s affiche a l ecran.
#  Ensuite une ligne par renseignement, sous la forme  nom = valeur.
#  Les lignes vides et les lignes commencant par # sont ignorees.
#
#      cle           Identifiant technique.
#                    Valeur cotee   -> symbole Yahoo Finance (ex. AIR.PA, ASML.AS)
#                    Fonds non cote -> code ISIN             (ex. QS0009080175)
#
#      enveloppe     PEG, PEA ou AV. Determine la section d affichage et le
#                    regroupement des plus-values.
#
#      source        Ou trouver la valeur du jour :
#                      yahoo       cotation en direct (actions et ETF)
#                      amundi-ee   API Amundi epargne salariale, pour les ISIN QS...
#                      amundi-fr   API Amundi grand public, pour les ISIN FR...
#                      abcbourse   page produit abcbourse.com, url obligatoire
#                      boursier    page produit boursier.com, url obligatoire
#
#      url           Adresse de la page produit. Uniquement pour abcbourse
#                    et boursier ; inutile pour les autres sources.
#
#      actions       Part de la valeur qui est investie en actions, entre 0 et 1.
#                    1 pour une action ou un ETF actions, 0 pour un monetaire ou
#                    un obligataire, une fraction pour un fonds mixte.
#
#      geo           Repartition de la POCHE ACTIONS par mandat d indice.
#                    Trois destinations possibles : monde, euro, emergents.
#                    Une seule    ->  geo = monde
#                    Un melange   ->  geo = monde 0.50 + euro 0.50
#                    Inutile de la renseigner si actions = 0.
#
# -----------------------------------------------------------------------------
#  L ORDRE DES BLOCS EST L ORDRE D AFFICHAGE a l interieur de chaque enveloppe.
#  Deplacer un bloc reorganise le tableau de bord, sans rien casser.
# -----------------------------------------------------------------------------
